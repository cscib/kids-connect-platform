Maltese Quest V1 API (1.0.0)

Download OpenAPI specification:

API specification for Maltese Quest V1 and the Kids Connect Platform layer.

Layer model

  • MQ — Maltese Quest product services (learning, challenges, recordings, progress).
  • KCP — Kids Connect Platform services (identity, profiles, contacts, permissions, safety).
  • SHSYS — Shared infrastructure (analytics, event bus, notifications).

Authentication

All endpoints use Bearer JWT tokens unless marked Public or Internal.

  • Parent token — scoped to the parent account and their household only.
  • Child token — scoped to one child profile; cannot access parent data.
  • Internal token — service-to-service calls only; never issued to a client.
  • Refresh token — used only on POST /auth/refresh; rotated on every use.

Global conventions

  • Base path: /v1
  • All responses are JSON unless the endpoint returns binary or stream data.
  • All list endpoints use cursor pagination unless otherwise stated.
  • All mutation endpoints that may be retried must be idempotent.
  • Event names use dotted lowercase format e.g. contact.request.created.
